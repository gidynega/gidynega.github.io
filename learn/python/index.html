Lesson 1: Introduction to Python

Python is a programming language that allows us to give instructions to computers. It is used in web development, automation, data analysis, artificial intelligence, and more.

Your first Python program

print("Hello, World!")
print("My name is Gidy")
print("I am learning Python")

How does it work?

  • print() tells Python to display something.
  • Text is placed inside quotation marks.
  • Each line is a separate instruction.
Remember: Python code must follow its syntax rules. For example, quotation marks must be properly opened and closed.

Lesson 2: Variables

A variable is a name used to refer to a value. Think of it as a labelled container for information. 

name = "Gidy"
age = 22
subject = "Pharmacy"

print(name)
print(age)
print(subject)

Understand each part

  • name is the variable's name.
  • = assigns the value to the variable.
  • "Gidy" is the value stored in the variable.
  • print(name) displays the value of the variable.
Important: name = "Gidy" stores text. But age = 22 stores a whole number.

Lesson 3: Python Data Types

A data type tells Python what kind of value you are working with.

name = "Gidy"       # str: text
age = 22            # int: whole number
height = 1.75       # float: decimal number
is_student = True   # bool: True or False

print(type(name))
print(type(age))
print(type(height))
print(type(is_student))

The four basic types

  • str: text, such as "Python".
  • int: whole numbers, such as 25.
  • float: decimal numbers, such as 3.14.
  • bool: either True or False.

Lesson 4: Input and Output

Use print() to display information and input() to receive information from a user. 

name = input("Enter your name: ")
print("Welcome,", name)

Important: input returns text

If you ask for a number, convert the input when you need to perform arithmetic. 

age = int(input("Enter your age: "))
next_year = age + 1

print("Next year you will be:", next_year)

Lesson 5: Conditions

Conditions allow your program to make decisions. Python uses if, elif, and else. 

mark = 75

if mark >= 80:
    print("Excellent")
elif mark >= 50:
    print("Pass")
else:
    print("Fail")

How the example works

  • If the mark is at least 80, print "Excellent".
  • Otherwise, if the mark is at least 50, print "Pass".
  • If neither condition is true, print "Fail".
Remember: The order matters. Python checks conditions from top to bottom and executes the first matching branch.

Lesson 6: Loops

A loop repeats instructions. A for loop is useful when going through a sequence or repeating a known number of times. 

for number in range(1, 6):
    print(number)

The output is:

1
2
3
4
5

range(1, 6) starts at 1 and stops before 6. That is why the number 6 is not printed.

A loop with a list

subjects = ["Python", "Pharmacy", "AI"]

for subject in subjects:
    print(subject)
