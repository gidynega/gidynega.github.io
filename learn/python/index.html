Lesson 1: Introduction to Python

Python is a programming language that allows us to give instructions to computers. It is used in web development, automation, data analysis, artificial intelligence, and more.

Your first Python program

print("Hello, World!")
print("My name is Gidy")
print("I am learning Python")

How does it work?

  • print() tells Python to display something.
  • Text is placed inside quotation marks.
  • Each line is a separate instruction.
Remember: Python code must follow its syntax rules. For example, quotation marks must be properly opened and closed.

Lesson 2: Variables

A variable is a name used to refer to a value. Think of it as a labelled container for information. 

name = "Gidy"
age = 22
subject = "Pharmacy"

print(name)
print(age)
print(subject)

Understand each part

  • name is the variable's name.
  • = assigns the value to the variable.
  • "Gidy" is the value stored in the variable.
  • print(name) displays the value of the variable.
Important: name = "Gidy" stores text. But age = 22 stores a whole number.

Lesson 3: Python Data Types

A data type tells Python what kind of value you are working with.

name = "Gidy"       # str: text
age = 22            # int: whole number
height = 1.75       # float: decimal number
is_student = True   # bool: True or False

print(type(name))
print(type(age))
print(type(height))
print(type(is_student))

The four basic types

  • str: text, such as "Python".
  • int: whole numbers, such as 25.
  • float: decimal numbers, such as 3.14.
  • bool: either True or False.

Lesson 4: Input and Output

Use print() to display information and input() to receive information from a user. 

name = input("Enter your name: ")
print("Welcome,", name)

Important: input returns text

If you ask for a number, convert the input when you need to perform arithmetic. 

age = int(input("Enter your age: "))
next_year = age + 1

print("Next year you will be:", next_year)

Lesson 5: Conditions

Conditions allow your program to make decisions. Python uses if, elif, and else. 

mark = 75

if mark >= 80:
    print("Excellent")
elif mark >= 50:
    print("Pass")
else:
    print("Fail")

How the example works

  • If the mark is at least 80, print "Excellent".
  • Otherwise, if the mark is at least 50, print "Pass".
  • If neither condition is true, print "Fail".
Remember: The order matters. Python checks conditions from top to bottom and executes the first matching branch.

Lesson 6: Loops

A loop repeats instructions. A for loop is useful when going through a sequence or repeating a known number of times. 

for number in range(1, 6):
    print(number)

The output is:

1
2
3
4
5

range(1, 6) starts at 1 and stops before 6. That is why the number 6 is not printed.

A loop with a list

subjects = ["Python", "Pharmacy", "AI"]

for subject in subjects:
    print(subject)

Lesson 7: Python Operators

Operators are symbols or keywords that perform operations on values and variables. They allow us to calculate, compare, and make decisions.

1. Arithmetic operators

These operators perform mathematical calculations.

a = 10
b = 3

print(a + b)   # Addition: 13
print(a - b)   # Subtraction: 7
print(a * b)   # Multiplication: 30
print(a / b)   # Division: 3.333...
print(a // b)  # Floor division: 3
print(a % b)   # Remainder: 1
print(a ** b)  # Exponentiation: 1000
  • + adds two values.
  • - subtracts one value from another.
  • * multiplies values.
  • / performs division.
  • // gives the floor of the quotient.
  • % gives the remainder.
  • ** raises a value to a power.
Example: 10 % 3 equals 1 because 3 goes into 10 three times, leaving a remainder of 1.

2. Comparison operators

Comparison operators compare values and produce True or False.

age = 20

print(age == 20)  # True: equal to
print(age != 18)  # True: not equal to
print(age > 18)   # True: greater than
print(age < 25)   # True: less than
print(age >= 20)  # True: greater than or equal to
print(age <= 19)  # False: less than or equal to
Important difference: = assigns a value, while == compares two values.

3. Logical operators

Logical operators combine or reverse conditions.

age = 22
is_student = True

print(age >= 18 and is_student)  # True
print(age < 18 or is_student)    # True
print(not is_student)           # False
  • and: True when both conditions are True.
  • or: True when at least one condition is True.
  • not: reverses True to False or False to True.

4. Real-life example

Imagine a student needs a mark of at least 50 to pass.

mark = 65

if mark >= 50:
    print("You passed!")
else:
    print("You failed.")

Python compares the mark with 50. Since 65 is greater than or equal to 50, the program displays You passed!

Lesson 8: Python Strings

A string is a sequence of characters used to represent text. A string can contain letters, numbers, spaces, and symbols.

1. Creating strings

name = "Gidy"
subject = 'Pharmacy'
message = "I am learning Python!"

print(name)
print(subject)
print(message)

You can create strings using single quotation marks or double quotation marks. Make sure the opening and closing quotation marks match.

2. Combining strings

Use the + operator to join strings together.

first_name = "Gidy"
last_name = "Nega"

full_name = first_name + " " + last_name

print(full_name)

Output:

Gidy Nega
Remember: The space inside " " creates a space between the two names.

3. Finding the length of a string

The len() function counts the characters in a string, including spaces and punctuation. 

word = "Python"

print(len(word))

Output:

6

4. Accessing characters with indexing

Each character has an index. Python starts counting from index 0, not 1. 

word = "Python"

print(word[0])  # P
print(word[1])  # y
print(word[2])  # t
print(word[-1]) # n

Positive indexing starts from the left. Negative indexing starts from the right, so word[-1] accesses the last character.

5. String slicing

Slicing extracts part of a string. The ending index is excluded. 

word = "Python"

print(word[0:2])  # Py
print(word[2:5])  # tho
print(word[:3])   # Pyt
print(word[3:])   # hon
Easy rule: In word[0:2], Python starts at index 0 and stops before index 2.

6. Useful string methods

text = "  Hello Python  "

print(text.upper())
print(text.lower())
print(text.strip())
print(text.replace("Python", "World"))

word = "pharmacy student"
print(word.title())

What these methods do:

  • upper() converts letters to uppercase.
  • lower() converts letters to lowercase.
  • strip() removes whitespace from the beginning and end.
  • replace() replaces matching text.
  • title() capitalizes the beginning of each word.

7. Checking whether text exists

message = "I am learning Python"

print("Python" in message)
print("Java" in message)

Output:

True
False

The in operator checks whether a substring appears in another string. String matching is case-sensitive.

8. Using f-strings

An f-string allows you to insert variable values directly into text. 

name = "Gidy"
subject = "Python"

print(f"My name is {name}.")
print(f"I am learning {subject}.")

Output:

My name is Gidy.
I am learning Python.

9. Real-life example

Let's create a simple student introduction.

name = "Gidy Nega"
field = "Pharmacy"
goal = "professional programmer"

print(f"My name is {name}.")
print(f"I study {field}.")
print(f"My goal is to become a {goal}.")

Lesson 9: Python Lists

A list is a collection that stores multiple items in a single variable. Lists are ordered, changeable, and allow duplicate values.

1. Creating a list

subjects = ["Python", "Pharmacy", "AI"]

print(subjects)

Output:

['Python', 'Pharmacy', 'AI']

Lists use square brackets [], and commas separate the items.

2. Lists can store different data types

student = ["Gidy", 22, 3.75, True]

print(student)

This list contains a string, an integer, a float, and a Boolean value. In most programs, using a consistent structure makes data easier to manage.

3. Accessing list items

Python uses indexing to access items. The first item has index 0. 

animals = ["Dog", "Cat", "Fish"]

print(animals[0])   # Dog
print(animals[1])   # Cat
print(animals[2])   # Fish
print(animals[-1])  # Fish
Remember: Indexing starts at 0. Negative index -1 refers to the last item.

4. Finding the number of items

animals = ["Dog", "Cat", "Fish"]

print(len(animals))

Output: 3

The len() function returns the number of items in a list.

5. Changing a list item

Lists are mutable, meaning you can change their items.

animals = ["Dog", "Cat", "Fish"]

animals[1] = "Lion"

print(animals)

Output:

['Dog', 'Lion', 'Fish']

6. Adding items to a list

subjects = ["Python", "Pharmacy"]

subjects.append("AI")
print(subjects)

subjects.insert(1, "Biology")
print(subjects)

Explanation:

  • append(item) adds an item to the end.
  • insert(index, item) adds an item at a chosen position.

7. Removing items

animals = ["Dog", "Cat", "Fish", "Cat"]

animals.remove("Cat")
print(animals)

last_animal = animals.pop()
print(last_animal)
print(animals)

Explanation:

  • remove(value) removes the first matching value.
  • pop() removes and returns the last item by default.
  • pop(index) removes and returns an item at a specified index.
  • del can delete an item or a slice.
  • clear() removes all items.

8. Slicing a list

Slicing extracts part of a list. The ending index is excluded. 

numbers = [10, 20, 30, 40, 50]

print(numbers[0:3])
print(numbers[2:])
print(numbers[:2])
print(numbers[-2:])

Output:

[10, 20, 30]
[30, 40, 50]
[10, 20]
[40, 50]

9. Looping through a list

A loop lets you process each item in a list.

subjects = ["Python", "Pharmacy", "AI"]

for subject in subjects:
    print(subject)

Output:

Python
Pharmacy
AI

10. Checking whether an item exists

subjects = ["Python", "Pharmacy", "AI"]

print("Python" in subjects)
print("Java" in subjects)

Output:

True
False

11. Sorting a list

numbers = [5, 2, 9, 1, 7]

numbers.sort()
print(numbers)

numbers.sort(reverse=True)
print(numbers)

sort() sorts the list in place. By default, it sorts numbers in ascending order. With reverse=True, it sorts them in descending order.

12. A practical student example

Imagine keeping track of student marks.

marks = [75, 82, 68, 90, 55]

print("Number of students:", len(marks))
print("First student's mark:", marks[0])

marks.append(88)

average = sum(marks) / len(marks)

print("Updated marks:", marks)
print("Average mark:", average)

Here, sum() adds the marks, and len() counts them. Dividing the total by the count calculates the average.

13. Common mistakes

  • IndexError: Trying to access an index that does not exist, such as animals[5] in a three-item list.
  • Wrong brackets: Lists use square brackets [] for indexing.
  • Confusing append and extend: append([3, 4]) adds one list as a single item, while extend([3, 4]) adds its items individually.
